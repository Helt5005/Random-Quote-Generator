# Random Quote Generator

## Автор
Старченко Константин

## Описание
GUI-приложение на Python для генерации случайных цитат с возможностью фильтрации, сохранения истории и добавления новых записей.

## Функциональность
- Генерация случайных цитат
- Фильтрация по автору и теме
- Добавление новых цитат
- Валидация пользовательского ввода
- Сохранение истории в JSON
- Загрузка истории при запуске

## Запуск
1. Установить Python 3
2. Скачать проект
3. Запустить:
4. python main.py

## Примеры использования

### Позитивные случаи:
- Генерация цитаты без фильтра
- Фильтрация по автору "Аристотель"

### Негативные случаи:
- Пустые поля при добавлении
- Несуществующий автор

### Граничные случаи:
- Один элемент в списке
- Пустой список цитат
