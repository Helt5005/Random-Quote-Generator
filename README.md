# Random Quote Generator

## Автор
Старченко Константин

## Описание
GUI-приложение на Python для генерации случайных цитат с фильтрацией, историей и сохранением данных.

## Функциональность
- Генерация случайных цитат
- Фильтрация по автору и теме
- Добавление новых цитат
- Проверка на дубликаты
- Сохранение истории в JSON
- Обработка ошибок

## Запуск

Требуется Python 3.

1. (Рекомендуется) создать виртуальное окружение:
   python -m venv venv

2. Активировать:
   Windows:
   venv\Scripts\activate

   macOS/Linux:
   source venv/bin/activate

3. Запуск:
   python main.py

## Примеры использования

Позитивные:
- Генерация без фильтра
- Фильтр по автору

Негативные:
- Пустые поля
- Дубликаты

Граничные:
- Нет совпадений
